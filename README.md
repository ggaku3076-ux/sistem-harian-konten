# PropPulse — Sistem Konten Harian Pemasaran Properti

Sistem pencatatan & analitik konten harian bergaya minimalis untuk **Manajemen Pemasaran Properti (Rumah Subsidi & Komersil)**.

## Fitur Utama
- **Multi-Halaman & Multi-Navbar**: Beranda, Input Harian (3 langkah terstruktur), Performa (3 sub-analitik), dan Riwayat.
- **Produksi & Distribusi Konten**: Pencatatan tanggal, fokus unit (`Rumah Subsidi` / `Rumah Komersil` / `Keduanya`), jumlah konten dibuat, distribusi **TikTok (TT)**, **Instagram (IG)**, **Facebook (FB)**, sebaran grup video, serta listing marketplace.
- **Metrik Engagement Terpisah + Otomatis**: Input terpisah per aplikasi (`TT`, `IG`, `FB`) untuk *Views, Likes, Comments, Shares, Saves, & Klik WA* dengan penjumlahan total dan *Engagement Rate (ER%)* otomatis.
- **Live Streaming & Pipeline Prospek KPR**: Pencatatan sesi live, total prospek WA masuk, minat Subsidi vs Komersil, jadwal survey lokasi, dan booking/berkas KPR.
- **Wheel Performa Interaktif**: Analisis *Performa Satu-Satu*, *Performa Mingguan* (Senin–Minggu), dan *Performa Gabungan* lengkap dengan Donut Wheel & Concentric Target Rings.
- **Save, Salin WA, & Export**: Penyimpanan lokal (`localStorage`), salin rekap WhatsApp 1-klik, Export Excel (`.csv`), serta Backup/Restore `.json`.

## Menjalankan Proyek
```bash
npm install
npm run dev
```
